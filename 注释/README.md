# ─────────────────────────────────────────────────────────────
# 注释目录 —— Emon DSL 项目详细中文注释版
# ─────────────────────────────────────────────────────────────
#
# 本目录是对原始 Emon DSL 编译器项目的完整逐行中文注释版。
# 原始项目是一个用于 eBPF（扩展伯克利包过滤器）监控的领域特定语言编译器。
#
# 项目整体架构分为五个层次：
#
#   .emon 源文件（用户编写的监控脚本）
#        │
#        ▼
#   ┌─────────────────────────────────────────┐
#   │  第一层：词法分析 (Lexer)               │  emon/lexer.py, emon/tokens.py
#   │  将源代码文本拆分为 Token 序列           │
#   └─────────────────────────────────────────┘
#        │
#        ▼
#   ┌─────────────────────────────────────────┐
#   │  第二层：语法分析 (Parser)              │  emon/parser.py, grammar/emon.lark
#   │  将 Token 序列构建为 抽象语法树 (AST)    │
#   └─────────────────────────────────────────┘
#        │
#        ▼
#   ┌─────────────────────────────────────────┐
#   │  第三层：语义分析 (Semantic Analyzer)   │  emon/semantic.py
#   │  检查变量作用域、类型正确性等            │
#   └─────────────────────────────────────────┘
#        │
#        ▼
#   ┌─────────────────────────────────────────┐
#   │  第四层：中间表示 (IR)                  │  emon/ir.py
#   │  将 AST 转换为编译器内部的数据结构       │
#   └─────────────────────────────────────────┘
#        │
#        ▼
#   ┌─────────────────────────────────────────┐
#   │  第五层：代码生成 (Code Generation)     │  emon/bpfc_gen.py,
#   │  生成 eBPF C 代码、加载器、清单文件      │  emon/loader_gen.py,
#   │                                          │  emon/manifest_gen.py
#   └─────────────────────────────────────────┘
#        │
#        ▼
#   .bpf.c (eBPF 内核态程序)
#   _loader.c (用户态加载器)
#   .yaml (工具清单描述文件)
#
# 最终产物通过 clang/llvm 编译为 eBPF 字节码，
# 加载到 Linux 内核中运行，实现系统可观测性监控。
# ─────────────────────────────────────────────────────────────
