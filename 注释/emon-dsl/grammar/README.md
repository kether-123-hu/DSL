# ===================================================================
# grammar/ 目录 —— 语法定义文件
# ===================================================================
#
# 【目录用途】
# 存放 Emon DSL 的"语法规则"定义文件。
# 语法规则就像语言的"法律"——它规定了什么样的写法是合法的 Emon 代码，
# 什么样的写法会报语法错误。
#
# 【文件说明】
#   emon.lark → Lark 格式的语法定义
#     Lark 是一个 Python 的解析框架。我们用 .lark 文件定义：
#       - 词法规则（什么构成一个合法的"单词"）
#       - 语法规则（单词怎么组合成合法的"句子"）
#       例如：
#         observe_stmt: "observe" observe_target where_clause? block
#       这条规则说：观察语句由 "observe" 关键字开头，后面跟观察目标、
#       可选的 where 子句，然后是代码块。
