# ===================================================================
# manifest/ 目录 —— 工具清单模板
# ===================================================================
#
# 【目录用途】
# 存放 eBPF 工具的 YAML 格式清单(manifest)模板和生成器输出。
# 清单文件用机器可读的方式描述了工具的结构：
#   - 工具名称和版本
#   - 配置选项
#   - BPF map 定义
#   - 探针(probe)挂载点
#   - 事件结构
#   - 生命周期（begin/every/end）
#
# 【文件说明】
#   tool_manifest.yaml → 清单模板
#     编译器 manifest_gen.py 会读取 IR，填充此模板中的占位符，
#     生成最终的工具描述文件。这个文件用于工具发现和管理。
# ===================================================================
