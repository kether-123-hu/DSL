# ===================================================================
# src/runtime/ 目录 —— C 语言运行时库源码
# ===================================================================
#
# 【目录用途】
# 存放用 C 语言编写的用户态运行时辅助库。
# 这些代码会被编译成一个静态库（libemon-rt.a），
# 然后与编译器生成的 _loader.c 链接在一起，形成最终的可执行监控工具。
#
# 【为什么需要运行时库？】
# 编译器生成的 _loader.c 只包含"特定于这个监控工具"的逻辑
# （比如加载哪个 BPF 程序、每隔几秒打印什么数据）。
# 而"通用的"功能（比如怎么遍历 BPF map、怎么打印直方图、怎么处理信号）
# 被提取到这个运行时库中，所有生成的工具都可以复用。
#
# 【子目录说明】
#   loader/ → BPF 程序的加载和生命周期管理
#     emon_rt_loader.c: 信号安装、BPF 对象打开/加载/挂载、主循环休眠
#
#   map/    → BPF Map 数据读取
#     emon_rt_map.c: 遍历 hash map、排序、输出 top-N 统计
#
#   output/ → 格式化输出
#     emon_rt_output.c: 直方图打印、表格打印、条形图打印、ring buffer 轮询
#
#   CMakeLists.txt → 将这 3 个 .c 文件编译为 libemon-rt.a 静态库
# ===================================================================
